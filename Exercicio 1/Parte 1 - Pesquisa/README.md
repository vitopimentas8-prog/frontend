1. O que é Frontend?
O Frontend é a parte de um site ou aplicativo com a qual o usuário interage diretamente. É tudo aquilo que aparece na tela, como textos, imagens, menus, botões, formulários e cores.

O desenvolvimento Frontend tem como objetivo criar interfaces bonitas, organizadas, acessíveis e fáceis de utilizar. Para isso, utiliza principalmente HTML, CSS e JavaScript.

Exemplo: em um site de compras, a página dos produtos, o botão “Adicionar ao carrinho” e o menu de navegação fazem parte do Frontend.

2. O que é Cliente x Servidor?
O modelo Cliente x Servidor é uma forma de comunicação entre dois sistemas: o cliente solicita informações ou serviços, e o servidor recebe essas solicitações, processa-as e envia uma resposta.

Cliente: geralmente é o navegador, como Google Chrome ou Firefox, utilizado pelo usuário para acessar um site.

Servidor: é o computador ou sistema responsável por disponibilizar páginas, processar solicitações e, quando necessário, acessar bancos de dados.

Comunicação: acontece por meio de protocolos como HTTP e HTTPS, que permitem a troca de solicitações e respostas.

Exemplo prático: quando uma pessoa acessa um site, o navegador (cliente) solicita a página ao servidor. O servidor envia os arquivos necessários, e o navegador os interpreta para exibir o site na tela.

3. Qual é o papel do HTML, CSS e JavaScript?
As três tecnologias trabalham juntas para construir páginas web, mas cada uma possui uma função específica.

HTML — Estrutura
O HTML (HyperText Markup Language) é uma linguagem de marcação utilizada para organizar o conteúdo da página, como títulos, parágrafos, imagens, links e formulários.

Exemplo: definir o título e o texto de uma página.

CSS — Aparência
O CSS (Cascading Style Sheets) é utilizado para definir a aparência visual da página, incluindo cores, fontes, espaçamentos, tamanhos e posicionamento dos elementos.

Exemplo: deixar um título azul e centralizado.

JavaScript — Interatividade
O JavaScript é uma linguagem de programação que permite adicionar comportamentos dinâmicos à página, responder a cliques, validar formulários e atualizar informações sem precisar recarregar toda a página.

Exemplo: fazer aparecer uma mensagem quando o usuário clica em um botão.

4. O que é W3C?
O W3C (World Wide Web Consortium) é uma organização internacional que desenvolve padrões e recomendações para a Web. Seu objetivo é promover uma Web que funcione de maneira consistente em diferentes navegadores e dispositivos, além de incentivar a acessibilidade e a interoperabilidade.

O W3C reúne empresas, especialistas e outras partes interessadas para desenvolver padrões que orientam a criação de tecnologias web.

Exemplo: os padrões e as recomendações relacionados ao HTML e ao CSS ajudam desenvolvedores a criar páginas que possam ser interpretadas de forma consistente por diferentes navegadores.
