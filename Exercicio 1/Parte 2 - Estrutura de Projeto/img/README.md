
# Parte 2 - Estrutura de Projeto

## Objetivo

Organizar os arquivos de um projeto web, separando a estrutura HTML,
a estilização CSS, os comportamentos JavaScript e as imagens.

## Estrutura do projeto

### index.html
É o arquivo principal da página web. Contém a estrutura do conteúdo
em HTML e faz a ligação com os arquivos CSS e JavaScript.

### css/
Pasta destinada aos arquivos de folhas de estilo CSS, responsáveis
pela aparência visual das páginas.

#### style.css
Define cores, fontes, espaçamentos, tamanhos e outros estilos visuais
dos elementos HTML.

### js/
Pasta destinada aos arquivos JavaScript, utilizados para adicionar
interatividade e comportamentos às páginas.

#### script.js
Contém o código JavaScript do projeto, como funções, eventos e
outras funcionalidades interativas.

### img/
Pasta destinada ao armazenamento das imagens utilizadas no projeto,
como fotografias, ilustrações, ícones e logotipos.

### README.md
Arquivo de documentação que apresenta o objetivo do projeto e
explica a finalidade de cada pasta e arquivo.

### .gitkeep
Arquivo auxiliar que permite manter a pasta img/ no controle de
versão do Git enquanto ela estiver vazia.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
