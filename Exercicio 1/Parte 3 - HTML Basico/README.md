
# Parte 3 - HTML Básico

## Objetivo

Aprender a estrutura básica de um documento HTML e conhecer as principais tags utilizadas para organizar o conteúdo de uma página web.

## Tags utilizadas

- `<!DOCTYPE html>`: informa ao navegador que o documento utiliza HTML5.
- `<html>`: elemento raiz que contém todo o documento HTML.
- `<head>`: contém informações sobre a página e configurações do documento.
- `<meta>`: define metadados, como a codificação de caracteres e a configuração de visualização em dispositivos móveis.
- `<title>`: define o título exibido na aba do navegador.
- `<body>`: contém o conteúdo da página que será apresentado ao usuário.
- `<h1>`: define o título principal da página.
- `<h2>`: define subtítulos que organizam o conteúdo em seções.
- `<p>`: cria um parágrafo de texto.
- `<ul>`: cria uma lista não ordenada, normalmente exibida com marcadores.
- `<ol>`: cria uma lista ordenada, normalmente exibida com números.
- `<li>`: representa um item dentro de uma lista ordenada ou não ordenada.

## Conteúdo desenvolvido

O arquivo `index.html` apresenta uma introdução ao HTML, uma lista de tecnologias web e uma lista ordenada com passos para estudar Frontend.
