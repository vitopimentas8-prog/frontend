# Mundo Tech — Projeto Final

## Objetivo
Criar uma página web educativa sobre tecnologia e informática, praticando HTML semântico, organização de arquivos, CSS, links, imagens acessíveis e uma interação simples com JavaScript.

## Estrutura de pastas
```text
Parte 5 - Projeto Final/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── img/
│   └── .gitkeep
└── README.md
```

A imagem principal é carregada de um endereço externo do Unsplash; a pasta `img/` fica reservada para imagens locais do projeto.

## Como abrir o projeto
1. Baixe ou clone o repositório.
2. Abra a pasta `Exercicio 1/Parte 5 - Projeto Final`.
3. Abra o arquivo `index.html` em um navegador atualizado.
4. Para desenvolvimento, também é possível abrir a pasta no Visual Studio Code e usar a extensão Live Server.

Não é necessário instalar dependências ou executar um servidor para visualizar a página.

## Validação e revisão
- Revisão da estrutura do documento e presença de `header`, `nav`, `main`, `section` e `footer`.
- Conferência dos caminhos relativos para CSS e JavaScript.
- Conferência da presença de texto alternativo (`alt`) na imagem e de links externos com `rel="noopener noreferrer"`.
- Revisão da interação do botão de dica, incluindo o atributo `aria-expanded`.
- Revisão das regras CSS para telas menores.
- A revisão foi estática do código-fonte; o teste final em navegador deve ser realizado no ambiente local.
